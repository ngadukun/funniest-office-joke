Entry for the [make.fun bounty](https://make.fun/c/u-kevin-the-funniest-office-joke-judged-head-to-head-3dc3233c): a single original funny one-line office joke.

`main.ts` (Node 22, standard library only, no network, deterministic) writes the line to `output/entry.txt` and prints it to stdout. A hard guard refuses to run if the line ever exceeds 200 characters or is not a single clean line.

## Run

```sh
node main.ts
```
